# aMBR Genomics interview notes

The interview form is a Google web app. This repository is the page the team uses to open it. The form is not a file in the NSF I-CORPS Drive folder, and it is not filled in on GitHub.

**[Open the interview form](https://script.google.com/a/macros/wisc.edu/s/AKfycbyGPoxpnnK9zqBtJoUbqLSGVWB8i-a6h6enjga0e-IxUR8Umb-XfarkDGsr71zwBC7l7A/exec)**

Sign in with a `@wisc.edu` Google account first, then click that link. A private window cannot open it. The interviewee does not use this page.

## What happens when you save

1. Choose the interviewee's perspective, the topic, and how the interview was arranged.
2. Four prompts for that perspective appear. Type what they said. Leave out names and identifiers.
3. Confirm and save. The page shows an 8-character confirmation.
4. One new row is added to the `Responses` tab of the private team spreadsheet.

The script writes that row. Interviewers do not need edit access to the spreadsheet.

Setup, the spreadsheet link, and how to update the live page are in [`aMBR_Public_Questionnaire_v4_deployable`](aMBR_Public_Questionnaire_v4_deployable/README.md).
